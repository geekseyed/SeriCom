SeriCom — Automated Serial File Transfer Tool
SeriCom is a lightweight Windows application (WPF, .NET Framework 4.8) forautomated file transfer between two computers over a serial (COM) port.

Features
File send / pull between two PCs over serial port
Scheduled tasks for daily automatic transfers
Work log and transfer records with timestamps
Password protection
Clean English UI
Requirements
Windows 10/11
.NET Framework 4.8
Serial cable or USB-to-serial adapters between the two machines
Build
Open ComTransfer.sln in Visual Studio 2022 and build.NuGet packages restore automatically.
